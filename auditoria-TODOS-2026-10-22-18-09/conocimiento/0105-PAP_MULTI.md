Guía de carga de consumos en promociones PAP Digital 2*1  Estimado farmaceútico en el caso de las nuevas promociones de PAP Digital 2*1, para proceder a la validación es necesario cargar los consumos originales que debe efectuar primero el paciente. Primero veamos un ejemplo, en la página https://digital.bonospap.com.ar/ pueden consultar por el DNI de un paciente los bonos que tiene asignados ingresando en “Consulta de Bonos”.

La consulta nos informa que bonos tiene asignados el paciente, en este caso vemos un bono normal (Prebien) y una promoción 2*1 (Myrbetric), si observamos el caso del Myrbetric vemos que el mismo se encuentra resaltado en amarillo y nos indica que tiene cero consumos Originales Registrados:

Esto significa que si se intentan validar bonos para ese paciente solo nos permitirá validar el Prebien (Promoción tradicional):

Para poder validar el bono 2*1 el afiliado tienen que realizar primero los consumos originales para que se permita la validación. Esos consumos se pueden   ingresar   en   la   páginas   https://www.bonospap.com.ar/   y   https://www.misvalidaciones.com.ar/.   En   el   primer   caso   en   la   sección “Farmacias”/”Consumos Bono PAP Digital” ingresando el número de bono pueden cargar los consumos:

Se debe indicar fecha de compra, el número de ticket y la cantidad, luego se selecciona guardar para registrar el consumo:

Si se desea registrar el consumo por la página de mis validaciones el procedimiento es el siguiente: ingresando con el usuario y clave se dirigen a “Bonos Consulta – Registra Consumos”

Ingresando el número de bono (sin “/”) se puede ingresar el consumo original en “Consumos”:

Indicando también fecha de compra, el número de ticket y la cantidad, luego se selecciona guardar para registrar el consumo:

Indistintamente de la página que se utilice para registrar el consumo, si se intenta validar, vemos que una vez registrado el consumo original nos permite validar el producto:
